# ReadMe (RAG Test Corpus)

This folder contains a OneNote-friendly export of the attached HP Troubleshooting Guide PDF.

Use it to create a OneNote notebook (Option C test) and compare RAG results between:
1) the original PDF, and 2) OneNote pages built from these markdown files.

Included:
- Pre-split pages by topic
- A PowerShell script scaffold to generate a OneNote notebook via OneNote COM API (desktop)

Source: TS_GUIDE.pdf
